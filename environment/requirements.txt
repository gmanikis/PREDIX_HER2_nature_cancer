# What has actually been verified, and what has not:
#
#   VERIFIED. The reporting and verification layer — every table, figure and

#   with Python 3.14 and current releases, reproducing 179,350 deposited

#   |diff| = 0.
#
#   NOT VERIFIED. The full model-fitting pipeline has NOT been re-run end to end

#   over 1,000 folds, which are sensitive to exactly that.
